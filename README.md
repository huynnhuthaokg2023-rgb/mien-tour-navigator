# Miền Tour Explorer (22)

PROMPT XÂY DỰNG WEBSITE MIỀN TOUR

Hãy xây dựng một website du lịch số chuyên nghiệp có tên MIỀN TOUR.

MIỀN TOUR là một nền tảng khám phá du lịch địa phương, giúp người dùng tìm hiểu các địa danh, xem thông tin, hình ảnh, video, nghe thuyết minh bằng tiếng Việt hoặc tiếng Anh và xem vị trí trên Google Maps.

Website phải được xây dựng như một sản phẩm công nghệ du lịch thực tế, có giao diện chuyên nghiệp, trải nghiệm người dùng tốt, có Database, hệ thống đăng nhập quản trị và Admin Dashboard để quản trị viên có thể tự cập nhật nội dung trong tương lai mà không cần chỉnh sửa code.

Ưu tiên trải nghiệm người dùng trên điện thoại.

Hãy tạo giao diện đầu tiên thật chuyên nghiệp và sau đó đảm bảo tất cả chức năng quản trị, Database và Storage có thể hoạt động thực tế.

Nếu có chức năng cần kết nối dịch vụ bên ngoài, hãy hướng dẫn rõ ràng từng bước để thiết lập và kết nối.
